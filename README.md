# 黄油·数据库桌宠

当前版本 **v2.0.0**。酒馆助手脚本，配合提供 `AutoCardUpdaterAPI.deskPet` 的神·数据库使用。

## 安装

1. 在酒馆助手里停用旧版黄油替换脚本（v1系列已废弃）。
2. 下载仓库根目录的 **黄油数据库桌宠_在线入口.json**，导入酒馆助手并启用。
3. 加载数据库并打开其桌宠。首次加载需要联网；失败保留数据库原画面，可点“应用黄油桌宠”重试。

关闭脚本或点“恢复数据库原图”会清除黄油画布，显示数据库原图。旧版曾持久保存黄油图片，新版首次运行会按已知图片摘要与本机恢复记录恢复，保留后来手改项；缺少恢复记录时需要在数据库设置里自行恢复旧图片。

## 互动

- 头顶短点：暴栗两段。长按约550ms或滑动：持续摸头；松手先完成本轮，再完整播放结束段。
- 脸部短点：尴尬。长按或拖动：原模型骨骼薅脸；松手320ms回弹后完整播放3.2秒哭哭收尾。
- 身体三连点：完整挠痒三段。拖身体/腿部：原数据库移动和位置保存。
- 待机：14种模型动作随机播放，相邻不重复。沿用数据库待机间隔与自动动作开关；工作、睡觉、拖动、探头、失焦时让出待机动作。
- 四边探头：直接渲染头部骨骼，保留呆毛。点击探头仍由数据库唤出。
- “调整桌宠大小”：电脑/手机各32～256px。大小保存于数据库，关闭脚本保留所选大小。

## 在线更新

导入一次入口即可。每次启动、每30分钟以及点击“检查在线更新”时读取 `manifest.json`。运行时采用版本目录与SHA256校验，新模型准备好、当前互动播完后切换；网络失败、内容损坏或版本不一致时继续使用已运行版本。首次加载失败则保留数据库原图。

首次需要可访问 GitHub Raw 和 jsDelivr。此入口没有持久离线缓存；重启后离线时显示数据库原图。未来若修改入口协议，需要重新导入入口JSON。

## 开发

修改 `src/online-runtime.js` 的代码与版本，运行 `node build.cjs` 生成版本目录、manifest和入口JSON。既有发布版本目录不可覆盖，新增版本再更新清单。不要向本仓库提交游戏模型、凭据、日志、缓存或测试截图。

v2已在真实上游DeskPet.vue的本地Edge夹具中验证互动、拖动、尺寸、四边探头、停止还原、v1迁移、更新失败和完整动作结束后成功切换。夹具只将宿主配置/位置保存替换为内存存储，模型与Spine解析/渲染真实执行。未在用户实际酒馆环境安装验收。
