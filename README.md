# 嘟嘟脸数据库桌宠

给奶·数据库的桌宠换上 **黄油、柯米、咏春或夏乐**，支持摸头、薅脸、挠痒、拖动、四边探头和任务表情。人物名单可以在线刷新；下载过的角色保存在当前浏览器中，可以离线切换，关闭脚本会恢复数据库原图、调整前大小和提示。

**当前在线版本：v2.10.0**

[下载在线脚本](https://github.com/robot234/butter-database-pet/releases/download/v2.10.0/Trickcal-Database-Pet-v2.10.0.json) · [查看本版 Release](https://github.com/robot234/butter-database-pet/releases/tag/v2.10.0) · [仓库入口 JSON](./黄油数据库桌宠_在线入口.json)

> **已导入v2.9.0入口：打开“选择桌宠角色”，点“刷新在线人物”，再选夏乐即可，无需重新导入。** v2.8.0及更早入口把人物名单写死，需要先停用旧脚本，再导入本版一次。此前的v2.8.0“_本地”试用包继续保留，从本地包切换在线模式时也需要导入在线入口。

## 安装与启用

需要酒馆助手，以及提供桌宠外观接口的数据库。数据库须已加载，原生桌宠须已打开。

1. 停用已有的黄油／嘟嘟脸替换脚本，避免重复启用。
2. 下载上方的 `Trickcal-Database-Pet-v2.10.0.json`，导入酒馆助手并启用。
3. 新装默认显示黄油，已有公开版用户沿用之前的角色选择。
4. 点击“选择桌宠角色”，选择夏乐、咏春、黄油或柯米；成功后记住选择。

首次使用角色需要联网。加载失败时原图或当前角色保留；网络恢复、数据库加载完成后，从角色菜单重新选择即可重试。本地预览版的角色记忆独立，切到在线版后可在菜单里重新选择咏春。

## 四个按钮

| 按钮 | 用途 |
| --- | --- |
| 选择桌宠角色 | 切换人物；面板中的“刷新在线人物”可读取新人物，恢复原图或加载失败后也可使用 |
| 恢复数据库原图 | 恢复原图、调整前大小与原提示，保留按钮和缓存 |
| 调整桌宠大小 | 电脑和手机统一调整，范围32～256px，提供常用尺寸快捷档位 |
| 检查在线更新 | 手动检查并加载新版；准备完成且当前互动收尾后再切换 |

脚本启用后自动加载，无需点击“应用桌宠”。

以后人物完成适配并上线后，只需在角色面板点“刷新在线人物”，再点名字切换。名单读取成功不会强制更换当前角色或预下载所有模型；抓取失败保留原名单和当前画面。菜单、选择校验、启动恢复共用同一份名单，成功名单会缓存到当前浏览器。启动优先读缓存，不会自动联网刷新；入口按钮或加载协议改变时仍可能需要重新导入。

## 怎么互动

| 部位／操作 | 反应 |
| --- | --- |
| 短点头顶 | 敲头；短时间连续敲击会追加反应 |
| 长按或滑动头顶 | 摸头，松手后完整播放收尾 |
| 短点脸部 | 轮换7种表情 |
| 长按或拖动脸部 | 薅脸，松手回弹，再播放收尾和哭哭 |
| 点击、按住或小幅来回揉肚子 | 挠痒，松手后完整收尾 |
| 单向拖动肚子超过8px，或拖腿部／外围 | 移动桌宠，由数据库保存位置 |
| 悬停或点击屏幕边缘的探头 | 唤出桌宠 |

任务执行时也能拖动。互动收尾期间点击会保留最新一次互动，结束后接播；失焦、隐藏或恢复原图会取消待播互动。咏春平时使用坐姿，散步时临时使用模型自带的站立腿交替迈步。

## 任务成功和失败是什么表情

| 角色 | 执行中 | 成功 | 失败 |
| --- | --- | --- | --- |
| 黄油 | 2种得意轮换 | 3种吐舌头轮换 | 2种晕晕轮换 |
| 柯米 | 3种困困轮换 | 3种吐舌头轮换 | 惊叫／惊讶轮换 |
| 咏春 | 数数／机器人轮换 | 胜利／开心轮换 | 慌张／难过轮换 |
| 夏乐 | 3种写字轮换 | 开心／跳舞轮换 | 慌张／抱歉／难过轮换 |

结果表情至少保留3秒；新任务开始时优先显示工作状态。结果依据数据库气泡的成功／失败状态，未提供明确结果时不会自行猜测。

黄油有40个模型动作，柯米有43个，咏春普通版有106个，夏乐普通版有53个。夏乐保留帽子、角、卷轴与羽毛笔，随机动作含读卷轴、写字、跳舞等24种。各角色分别适配互动区域、任务表情、随机动作和探头；不表示所有模型动作都有单独的操作入口。

## 下载、缓存与更新

- 咏春骨架、图集描述和贴图从[本仓库的固定提交](https://github.com/robot234/butter-database-pet/tree/6f9c1afab0390814573e8d74c2d923452d355561/assets/youngchun)读取，解决原资源站跨站读取受限的问题；不再从原资源站实时加载。
- 夏乐骨架、图集描述和贴图从[本仓库固定提交](https://github.com/robot234/butter-database-pet/tree/9c64abd478e5f59bcd6e5200cb54846660dfb192/assets/sherum)读取；夏乐和咏春都使用Spine4.1.56，共用运行库资源缓存，各自创建私有实例。黄油／柯米继续从原上游固定提交读取，使用4.2.109；不覆盖宿主的全局Spine对象。
- 首次下载逐项核对SHA256，成功后保存在当前浏览器、当前酒馆地址的IndexedDB中。入口自带本版自有适配代码，不内嵌游戏模型或第三方运行库。
- 后续启动、恢复后重新选择、已下载角色之间切换，优先使用校验通过的缓存，不会每次读取GitHub更新清单。咏春本地预览版使用的模型地址不同，首次启用在线咏春时会按新地址下载。
- “检查在线更新”手动触发运行版本更新；也可以从角色面板单独“刷新在线人物”。网络失败、资源损坏或摘要不一致时保留当前角色；新人物模型下载失败不覆盖上次成功运行版本，损坏缓存只补下载缺失项。
- 更换浏览器、酒馆地址、清除站点数据或结束隐私窗口后可能需要重新下载。离线使用的前提是酒馆和数据库本身仍能正常打开。

切换成功保留当前大小。停用、移除或恢复原图时清理画布与监听，还原原图、尺寸和提示，保留缓存和角色选择。停用时没有调整过的尺寸会保留；显式恢复但没有尺寸恢复记录时使用数据库默认大小。用户后来手动修改的设置会尽量保留，保存失败会提示并保留恢复记录。

## 开发

需要Node.js。在仓库目录运行 `node build.cjs`。

- `src/loader.js`：入口、缓存、角色菜单与在线更新。
- `src/online-runtime.js`：模型加载、渲染、互动和数据库适配。
- `src/meta.json`：导入脚本名称、说明与按钮。
- `manifest.json` 与 `releases/<版本>/runtime.js`：生成的更新清单与固定版本运行时。
- `assets/youngchun/`：咏春原始模型与来源说明；二进制文件保持原字节。

修改运行代码时先升级版本再构建，既有公开版本目录不可覆盖。本地试用包和在线版同为v2.10.0是本次指定的命名方式，本地包另加“本地”标注。
