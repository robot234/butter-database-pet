# 黄油·数据库桌宠

当前版本 **v2.2.0**。酒馆助手脚本，配合提供 `AutoCardUpdaterAPI.deskPet` 的神·数据库使用。2.2修复了入口的恢复/再次应用按钮，需要重新导入本版入口一次；以后动作更新仍可点“检查在线更新”。旧入口在线更新可获得新动作，但无法修复已经导入的旧按钮逻辑。

## 安装

1. 在酒馆助手里停用旧版黄油替换脚本（v1系列已废弃）。
2. 下载仓库根目录的 **黄油数据库桌宠_在线入口.json**，导入酒馆助手并启用。
3. 加载数据库并打开其桌宠。首次加载需要联网；失败保留数据库原画面，可点“应用黄油桌宠”重试。

点“恢复数据库原图”会清除黄油画布，保留入口按钮和所选大小，再点“应用黄油桌宠”即可重新加载；恢复期间自动/手动检查更新不会自行启用。关闭脚本才彻底清理入口。旧版曾持久保存黄油图片，新版首次运行会按已知图片摘要与本机恢复记录恢复，保留后来手改项；缺少恢复记录时需要在数据库设置里自行恢复旧图片。

## 互动

- 点击部位按当前模型的脸轮廓、头发和躯干范围转换到屏幕判断，跟随缩放、姿势和左右镜像。
- 头顶短点：暴栗两段；1.8秒内连续敲三次追加生气三段。长按约550ms或滑动：持续摸头；松手先完成本轮，再完整播放结束段。持续1.8～4.5秒（或横向累计滑动0.65个桌宠宽度）追加高兴1～2，4.5秒以上追加高兴3～5。
- 脸部短点：尴尬、惊讶、另一种尴尬、歪头反应依次轮换。长按或拖动：原模型骨骼薅脸；偏移每帧重新计算并限制幅度，长时间拉动也不会把头拉出画面。松手320ms回弹后完整播放3.2秒哭哭收尾。
- 肚子单击：完整挠痒三段；轻轻来回揉或按住：挠痒持续，松手完整收尾。开始挠痒前大幅单向拖动肚子（超过桌宠宽度12%），或拖腿部/外围：原数据库移动和位置保存。原数据库三连点挠痒仍接完整三段。
- 散步：原数据库实际位移驱动自己的左右腿骨交替迈步。当前黄油站立模型没有Walk动画，这套迈步是自有骨骼适配，不是可丽饼房间动作或原游戏走路动画；不增加独立移动计时器。
- 待机：14种模型动作随机播放，相邻不重复。沿用数据库待机间隔与自动动作开关；工作、睡觉、拖动、探头、失焦时让出待机动作。
- 执行任务显示得意（Proud_1）；数据库气泡的错误标记显示晕晕（Dizzy_1），成功标记显示吐舌头（Taunt_1）。仍在执行时优先显示得意，结果气泡消失后交回当前原生动作；读取气泡明确的状态类，不猜测文字。气泡关闭/静默而没有结果标记时不会猜测成败。
- 四边探头：直接渲染头部骨骼，按实际下巴贴住屏幕边缘，保留呆毛。全身画面按当前实际姿势调整显示范围，跳跃和摇摆不会裁掉呆毛、耳朵。点击探头仍由数据库唤出。
- “调整桌宠大小”：电脑/手机各32～256px。大小保存于数据库，关闭脚本保留所选大小。

## 在线更新

导入一次入口即可。每次启动、每30分钟以及点击“检查在线更新”时读取 `manifest.json`。运行时采用版本目录与SHA256校验，新模型准备好、当前互动播完后切换；网络失败、内容损坏或版本不一致时继续使用已运行版本。首次加载失败则保留数据库原图。

首次需要可访问 GitHub Raw 和 jsDelivr。此入口没有持久离线缓存；重启后离线时显示数据库原图。未来若修改入口协议，需要重新导入入口JSON。

## 开发

修改 `src/online-runtime.js` 的代码与版本，运行 `node build.cjs` 生成版本目录、manifest和入口JSON。既有发布版本目录不可覆盖，新增版本再更新清单。不要向本仓库提交游戏模型、凭据、日志、缓存或测试截图。

v2.2已在真实上游DeskPet.vue和NoticeBubble.vue的本地Edge夹具中验证四种单击反应及快速换表情、32/64/160/256px肚子识别、轻揉和拖动区分、三种摸头时长及连续敲头分支、原生实际散步位移驱动迈步/停止交回原动画，以及调大小→恢复→再应用三轮和加载取消竞态。持续薅脸、任务表情、四边贴边、40动作各6个取样时刻完整显示、v1迁移、更新失败保留当前版和互动结束后切换回归通过。夹具只将宿主配置/位置保存替换为内存存储，模型与Spine解析/渲染真实执行。未在用户实际酒馆环境安装验收。
