# 嘟嘟脸数据库桌宠

给神·数据库的桌宠换上 **黄油或柯米**，支持摸头、薅脸、挠痒、拖动、四边探头和任务表情。下载过的角色保存在当前浏览器中，可以离线切换；关闭脚本会恢复数据库原图、调整前大小和提示。

**当前版本：v2.7.0**

[下载可导入脚本](https://github.com/robot234/butter-database-pet/releases/download/v2.7.0/Trickcal-Database-Pet-v2.7.0.json) · [查看本版 Release](https://github.com/robot234/butter-database-pet/releases/tag/v2.7.0) · [仓库入口 JSON](./黄油数据库桌宠_在线入口.json)

> **旧版升级：先停用旧脚本，再导入 v2.7.0 一次。** 本版更改了入口和按钮，旧入口只点“检查在线更新”无法获得完整修复。已有浏览器模型缓存和角色选择可以继续使用。

## 安装与启用

需要酒馆助手，以及提供桌宠外观接口的神·数据库。数据库须已加载，原生桌宠须已打开。

1. 停用已有的黄油／嘟嘟脸替换脚本，避免重复启用。
2. 下载上方的 `Trickcal-Database-Pet-v2.7.0.json`，导入酒馆助手。
3. 启用脚本，首次联网加载后自动显示桌宠。
4. 点击“选择桌宠角色”，选择黄油或柯米。成功后会记住选择。

如果首次加载失败，原图会保留；网络恢复、数据库加载完成后，从“选择桌宠角色”重新选择即可重试。

## 四个按钮

| 按钮 | 用途 |
| --- | --- |
| 选择桌宠角色 | 切换黄油／柯米；恢复原图或加载失败后，也可从这里重新启用 |
| 恢复数据库原图 | 恢复原图、调整前大小与原提示，保留脚本按钮和缓存 |
| 调整桌宠大小 | 电脑和手机统一调整，范围32～256px，提供常用尺寸快捷档位 |
| 检查在线更新 | 手动检查并加载新版；准备完成且当前互动收尾后再切换 |

脚本启用后自动加载，已移除“应用桌宠”按钮。恢复原图后，选择角色即可再次启用。

## 怎么互动

| 部位／操作 | 反应 |
| --- | --- |
| 短点头顶 | 敲头；短时间连续敲击会追加反应 |
| 长按或滑动头顶 | 摸头，松手后完整播放收尾 |
| 短点脸部 | 轮换7种表情，可连续点击切换 |
| 长按或拖动脸部 | 薅脸，松手回弹，再播放收尾和哭哭 |
| 点击、按住或小幅来回揉肚子 | 挠痒，松手后完整收尾 |
| 单向拖动肚子超过8px，或拖腿部／外围 | 移动桌宠，由数据库保存位置 |
| 悬停或点击屏幕边缘的探头 | 唤出桌宠 |

执行任务时也能拖动。摸头、薅脸等完整收尾期间，拖动需等待该段播完；这期间点击会保留最新一次互动，结束后接着播放。失焦、隐藏或恢复原图会取消待播互动。

## 任务成功和失败是什么表情

| 角色 | 执行中 | 成功 | 失败 |
| --- | --- | --- | --- |
| 黄油 | 2种得意轮换 | 3种吐舌头轮换 | 2种晕晕轮换 |
| 柯米 | 3种困困轮换 | 3种吐舌头轮换 | 惊叫／惊讶轮换 |

结果表情至少保留3秒；新任务开始时优先显示工作状态。结果依据数据库气泡的成功／失败状态，未提供明确结果时不会自行猜测。

黄油模型有40个动作，柯米有43个动作；两个角色分别适配动作、脸部轮廓和悬停提示。

## 缓存、更新与恢复

- 首次使用某个角色需要下载模型和Spine运行库，成功后缓存在当前浏览器、当前酒馆地址中。入口自带本版自有运行代码。
- 后续启动、恢复后重新选择、已下载角色之间切换，优先使用校验通过的缓存；无需每次读取GitHub更新清单。
- 更新由“检查在线更新”手动触发。网络失败、资源损坏或摘要不一致时保留当前画面；损坏项会按需重新下载。
- 切换角色成功后保留当前大小。停用、移除脚本或恢复原图时，清理画布与监听，恢复原图、尺寸和提示；缓存和角色选择保留。
- 更换浏览器、酒馆地址、清除站点数据或结束隐私窗口后，可能需要重新下载。离线使用的前提是酒馆和数据库本身仍能正常打开。

停用时没有调整过的尺寸会保留；显式恢复原图但没有尺寸恢复记录时，使用数据库默认大小。用户后来手动修改的设置会尽量保留。保存失败会提示并保留恢复记录，便于重试。

## v2.7.0 包含的更新

相较仓库原有v2.5.0：

- 新增柯米，保留黄油；增加角色菜单、记住选择与分别缓存。
- 修复重复应用／重复选择后，再切换可能造成整页卡死的问题。
- 改善拖动起步延迟，肚子拖动门槛改为8px；动作设置约250ms刷新一次，减少每帧读取整份配置的开销。
- 移除“应用桌宠”，自动启用；恢复原图和首次加载失败后，角色菜单仍可使用。

本地对比测试中，同样拖动10px，桌宠位移从0px变为10px；约145～146帧／秒的测试场景中，完整配置读取从146次／秒降为4次／秒。这是本地夹具结果，实际流畅度仍取决于浏览器和设备。

## 开发

需要Node.js。在仓库目录运行：

```sh
node build.cjs
```

- `src/loader.js`：入口、缓存、角色菜单与在线更新。
- `src/online-runtime.js`：模型加载、渲染、互动和数据库适配。
- `src/meta.json`：导入脚本名称、说明与按钮。
- `manifest.json` 与 `releases/<版本>/runtime.js`：构建生成的更新清单与固定版本运行时。

修改运行代码时先升级版本，再构建。既有版本目录不可覆盖；发布仅包含预期源码、导入JSON、清单、说明和许可文件。
