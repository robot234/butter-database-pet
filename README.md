# 黄油·数据库桌宠

当前版本 **v2.4.1**。酒馆助手脚本，配合提供 `AutoCardUpdaterAPI.deskPet` 的神·数据库使用。本次修复动作结束突然跳位与部分点击被吞掉：平滑恢复移动，睡觉能点醒，收尾/工作时确认点击并在完成后接最新一次互动。已有2.3.2及以上入口点“检查在线更新”即可。普通HTTP下更旧入口需重新导入本版一次，以修复digest报错。保留至少3秒吐舌头、同类动作轮换、悬停提示与关闭脚本恢复原大小。

## 安装

1. 在酒馆助手里停用旧版黄油替换脚本（v1系列已废弃）。
2. 下载仓库根目录的 **黄油数据库桌宠_在线入口.json**，导入酒馆助手并启用。
3. 加载数据库并打开其桌宠。首次加载需要联网；失败保留数据库原画面，可点“应用黄油桌宠”重试。

电脑版若曾提示“Cannot read properties of undefined (reading 'digest')”，停用旧入口并导入本版。浏览器原生摘要接口不可用时，入口使用内置SHA-256，仍校验下载的运行时和Spine库摘要。此处是入口修复，旧入口不能仅靠“检查在线更新”取得。

点“恢复数据库原图”会还原调整前大小并清除黄油画布，保留入口按钮，再点“应用黄油桌宠”即可重新加载；恢复期间检查更新不会自行启用。旧版未留尺寸记录时，点恢复按钮会恢复数据库原始默认尺寸。恢复失败保留画面与记录，可重试；保留后来在数据库手改的尺寸项。关闭或移除脚本也会恢复原图和调整前大小，再彻底清理入口；在线更新保留当前大小。停用时保存失败仍清理画面并保留恢复记录，下次启用后可重试。未调整尺寸且无记录时停用不改尺寸。旧v1曾保存黄油图片，新版首次运行会按已知摘要与本机记录恢复，保留后来手改项；缺少旧图片记录时需要在数据库设置里自行恢复旧图片。

## 互动

- 鼠标悬停按黄油当前动作及部位显示对应操作：头顶敲头/摸头、脸部薅脸、肚子挠痒，任务状态与探头提示同步。恢复原图或关闭脚本时还原数据库原生提示及无障碍说明。
- 点击部位按当前模型的脸轮廓、头发和躯干范围转换到屏幕判断，跟随缩放、姿势和左右镜像。
- 头顶短点：暴栗两段；1.8秒内连续敲三次追加生气三段。长按约550ms或滑动：持续摸头；松手先完成本轮，再完整播放结束段。持续1.8～4.5秒（或横向累计滑动0.65个桌宠宽度）追加高兴1～2，4.5秒以上追加高兴3～5。
- 脸部短点：尴尬、惊讶、另一种尴尬、歪头、三种吐舌头依次轮换，共7种反应；Taunt类至少循环3秒，快速再次点脸可切下一种。长按或拖动：原模型骨骼薅脸；偏移每帧重新计算并限制幅度，长时间拉动也不会把头拉出画面。松手320ms回弹后完整播放3.2秒Touch_End，再轮换Sad_1～4哭哭尾段。
- 肚子单击：完整挠痒三段；轻轻来回揉或按住：挠痒持续，松手完整收尾。开始挠痒前大幅单向拖动肚子（超过桌宠宽度12%），或拖腿部/外围：原数据库移动和位置保存。原数据库三连点挠痒仍接完整三段。
- 散步：原数据库实际位移驱动自己的左右腿骨交替迈步。当前黄油站立模型没有Walk动画，这套迈步是自有骨骼适配，不是可丽饼房间动作或原游戏走路动画；不增加独立移动计时器。
- 待机：14种模型动作随机播放，相邻不重复。沿用数据库待机间隔与自动动作开关；仅在原生待机时开始，工作、睡觉、拖动、探头、失焦时让出待机动作。Taunt类待机动作至少3秒。
- 执行任务轮换2种得意（Proud_1/2）；数据库气泡错误标记轮换2种晕晕（Dizzy_1/2），成功标记轮换3种吐舌头（Taunt_1/3/4）。结果从实际播放起至少显示3秒，短气泡消失也不立即中断，之后交回原生动作；新工作立即优先。读取气泡明确的状态类，不猜测文字，气泡关闭/静默而没有结果标记时不会猜测成败。
- 互动与完整收尾时固定黄油画面位置/朝向，腿部和外围拖动等播完再操作并有等待提示；随机动作可由主动拖动取消。播完有位置差时平滑接回数据库位置，无位置差不增加拖动延迟；过渡中主动拖动通过原组件事件对齐当前可见起点，之后由数据库移动和保存。不修改数据库的移动配置，内部散步计时仍继续。恢复原图、停用或组件重建清理临时位置锁与过渡。
- 收尾或工作时点击头顶、脸部、肚子立即提示已收到，保留最新一次互动，完成当前动作后接播；短点不因等待被算成长按。连续敲头仍保留三连敲分支，快速点脸仍可换短表情。睡觉时点击交回数据库唤醒，哈欠时仍能互动。失焦、隐藏、组件更换或恢复/停用取消待播与提示。
- 同类原生反应也使用实际可用的动作版本。摸头只有一组Pat持续/结束，敲头与挠痒编号是连续阶段，仍完整按顺序播放，保留原时长/次数分支；未声称它们有多套原游戏互动。
- 四边探头：直接渲染头部骨骼，按实际下巴贴住屏幕边缘，保留呆毛。全身画面按当前实际姿势调整显示范围，跳跃和摇摆不会裁掉呆毛、耳朵。点击探头仍由数据库唤出。
- “调整桌宠大小”：一个滑块/输入框同时设置电脑与手机，32～256px；64/88/128/160/200/256px快捷选择。“恢复默认大小”读取数据库宽屏默认值（当前88px），同时应用到两端。恢复原图则还原两端各自调整前的设置；无记录时恢复数据库原始默认值（当前宽屏88/窄屏64px）。大小和记录在当前数据库站点保存，不提供额外的跨站点同步。

## 在线更新

导入一次入口即可。每次启动、每30分钟以及点击“检查在线更新”时读取 `manifest.json`。运行时采用版本目录与SHA256校验，新模型准备好、当前互动播完后切换；网络失败、内容损坏或版本不一致时继续使用已运行版本。首次加载失败则保留数据库原图。

首次需要可访问 GitHub Raw 和 jsDelivr。此入口没有持久离线缓存；重启后离线时显示数据库原图。未来若修改入口协议，需要重新导入入口JSON。
